A selective dip-buyer for the pump.fun paper replay: it buys only coins already punished 35-55% off a recent high, once the tape shows buyers stepping back in, and exits mechanically on take-profit, stop-loss, trailing giveback or staleness.

## Run it

```sh
node main.ts
```
